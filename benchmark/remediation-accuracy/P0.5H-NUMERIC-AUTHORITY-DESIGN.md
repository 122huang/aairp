# P0.5H Numeric Authoritative Integration — Design

Status: implementation complete, **not deployed**, numeric authority **default off**.

This change promotes only **NUMERIC / QUANTITATIVE Semantic Detection** into a controlled, gated supplemental Finding path. It does **not** give Semantic Detection as a whole Legal authority.

## Authoritative numeric allowlist (frozen Canonical Ontology)

Predicates (engine enum):

- `nutrient_retention`
- `comparative_performance`
- `measurable_specification`

Claim forms (engine enum; no new case-specific families):

- `quantified_product_benefit`
- `quantified_comparative`
- `bare_specification`

Relations allowed: `exact` | `upper_bound` | `lower_bound` | `range` | `approximate` | `comparative_delta` | `multiplicative`.

`unknown`, unresolved, ambiguous, competing readings: **ABSTAIN**.

## Families that stay SHADOW ONLY / HOLD

Certification / status, endorsement, ranking / scope, health semantic expansion, general non-numeric claims, competing / unresolved readings, Candidate Reading, remediation, rewrite: **not** authoritative in this release.

P0.5A Candidate Reading = NO-GO. P0.6 HOLD. P1 rewrite HOLD.

Open Risk remains `AAIRP_OPEN_RISK_MODE=stub`.

## Authority Gate (A–L)

DeepSeek output never becomes a Finding by itself. All of the following must hold:

A. grounding span is a substring of the advertising copy  
B. deterministic numeric anchors exist (digit / written number / range / explicit %)  
C. value consistent with anchors  
D. unit present and safely normalized  
E. quantity relation canonicalized (not `unknown`)  
F. metric attachment canonicalized  
G. semantic predicate canonicalized  
H. no `CONSISTENCY_CONFLICT`  
I. family ∈ allowlist above  
J. existing governed Legal mapping exists  
K. not unresolved / ambiguous  
L. not negative / non-material numeric context (discount, date, SKU, model, unrelated counts)

Any failure → SHADOW ONLY / ABSTAIN. Existing Rule / Playbook continue.

## Legal mapping

| Canonical family | Governed rule | Decision | Remediation |
| --- | --- | --- | --- |
| `nutrient_retention` / most `comparative_performance` / non-capacity `measurable_specification` | `demo-apac-sa-performance-claim` | WARN (from rule taxonomy) | `EVIDENCE_SUPPLEMENT` |
| `measurable_specification` + metric `capacity` | `demo-apac-sa-capacity-claim` | WARN | `EVIDENCE_SUPPLEMENT` |

DeepSeek does not emit PASS/WARN/REVIEW/REJECT, A–F, policy, evidence sufficiency, remediation, or rewrite.

If a future canonical family has no mapping: ABSTAIN + SHADOW_ONLY.

## Deduplication

If Rule or Playbook already produced a materially equivalent quantitative Finding (`demo-apac-sa-performance-claim`, `demo-apac-sa-capacity-claim`, `demo-apac-sa-comparative-claim`, or listed quantitative playbook risk types), Semantic Numeric Lane **does not** add a second UI Finding. Provenance is logged as `RULE+SEMANTIC_NUMERIC`.

## Supplemental Finding

Only when Rule/Playbook miss **and** the gate passes **and** `AAIRP_SEMANTIC_NUMERIC_AUTHORITY=on`:

`SEMANTIC_NUMERIC_SUPPLEMENTAL_FINDING` as a RULE-module Finding mapped to the governed rule id, with grounding span, `rf_semnum_` finding id, EVIDENCE_SUPPLEMENT. UI does not show DeepSeek reasoning.

## Evidence handoff

When the mapped Legal family is objective / substantiable (`EVIDENCE_SUPPLEMENT`), the Finding enters the **existing** Evidence relevance / sufficiency pipeline. Semantic Layer does **not** judge evidence sufficient.

## Latency

Numeric authority **awaits** the provider with `AAIRP_SEMANTIC_NUMERIC_TIMEOUT_MS` (default 20000). Fire-and-forget is reserved for general Semantic Shadow.

Offline P0.5E.2 / P0.5F DeepSeek v4-pro descriptive calls were typically **~16–22s p50**. Expect:

- p50: ~15–22s when the provider is reached  
- p95: may exceed 20s on slow Responses API turns  
- timeout: fall back to Rule / Playbook only; do not REVIEW or block submit  

Do not raise the bound to “wait forever”.

## Data sent / excluded

Sent: advertising copy, country, category, deterministic numeric anchors.

Not sent: Evidence PDFs, test reports, certification documents, user identity, Legal comments, audit history, contracts, credentials, DeepSeek reasoning.

Production copy still requires `AAIRP_SEMANTIC_SHADOW_DATA_APPROVED=true`.

## Feature flags (independent, runtime)

| Variable | Role | Default |
| --- | --- | --- |
| `AAIRP_SEMANTIC_SHADOW_MODE` | general Semantic Shadow | `off` |
| `AAIRP_SEMANTIC_NUMERIC_AUTHORITY` | `off` \| `shadow` \| `on` | `off` |
| `AAIRP_OPEN_RISK_MODE` | Open Risk | `stub` |

Turning numeric authority off does not require a rebuild.

## Fail-open

Timeout, provider error, invalid JSON/schema, grounding fail, normalizer abstain, consistency conflict, missing Legal mapping, missing data approval, missing key → semantic authority abstain. Rule / Playbook unchanged.
