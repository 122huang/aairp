# P0.5H Numeric Authoritative Integration — Rollout

Real review volume is low. No percentage canary is required. Do **not** auto-deploy from this implementation round.

## Stages

1. **Deploy code** with `AAIRP_SEMANTIC_NUMERIC_AUTHORITY` unset/`off`. Confirm production parity (Rule / Playbook / Open Risk stub).
2. **Production smoke** on existing numeric Rule-hit copy (e.g. historical 90% nutrients): still one Finding.
3. **`shadow`**: 100% eligible numeric shadow (not 10% sampling). Confirm DeepSeek calls, Authority Gate, logs. No user-visible Finding change.
4. **Human review** of a few real numeric proposals and gate outcomes.
5. **`on`**: supplemental Findings allowed when gate passes and Rule misses.

## Rollback

Set `AAIRP_SEMANTIC_NUMERIC_AUTHORITY=off`. Independent of `AAIRP_SEMANTIC_SHADOW_MODE`. Do not set Open Risk live as part of rollback or enablement.

## Data approval

Copy is only sent when `AAIRP_SEMANTIC_SHADOW_DATA_APPROVED=true`. Stage 3+ must have that approval; otherwise authority abstains (fail-open).
