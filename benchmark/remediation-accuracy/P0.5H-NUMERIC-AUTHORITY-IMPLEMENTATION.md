## Pipeline insertion

`ReviewPipelineService.runThroughOpenRisk` evaluates Rule (and vision re-eval), Playbook, Open Risk stub, then **if numeric authority ≠ off** awaits `SemanticNumericAuthorityService.apply` and appends at most one supplemental RULE Finding. `fuseDecision` then sees the merged Rule findings.

General Semantic Shadow remains fire-and-forget after report.

## Observability (JSONL)

Logged: correlation / review id, numeric authority mode, Rule finding refs, semantic numeric proposal, authority gate result, reject/abstain reason, supplemental Finding yes/no, grounding / canonical IR, provider/model, normalizer version, latency, Evidence handoff yes/no.

Not logged: API keys, DeepSeek reasoning, PII fields.

Default log dir: `data/semantic-numeric-authority-logs/` (gitignored).

## Kill switch

Set `AAIRP_SEMANTIC_NUMERIC_AUTHORITY=off` (or unset). No rebuild. Existing Rule / Playbook path is unchanged.
