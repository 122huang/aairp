## 2. 非硬拦（对照，避免混级）

| `cn-unsourced-sales-social-proof` | WARN / EVIDENCE_SUPPLEMENT | `demo-cn-unsourced-metrics` **v1** | 无来源销量 / 好评**数量**等；可补统计口径、期间、来源后重审 |

| CN 互联网「广告」标识 | INFO | `demo-cn-internet-ad-identifiable-tag` | 发布清单；**不抬**最终决策、**不进** REVIEW 理由 |

**混级分界（必须遵守）：**

- 文案含「第一 / 冠军 / 100% / 零差评 / 零投诉 / 零退货」等绝对化或等同表述 → 走 **`cn-art9-absolute` REJECT**（例：好评率 100%、满意率 100%、销量冠军）。
- **仅**无来源销量 / 好评数量、且**无**上述绝对化用语 → 走 **`cn-unsourced-sales-social-proof` WARN**（例：累计销量突破 1000 万台、超过 1000 万个五星好评）。
- 二者并存时，以硬拦为准（REJECT 优先）。
